# v0.2.0 — First qualified diagnostic release

v0.2.0 is Bedrock's first qualified diagnostic release under D-425, D-441 and D-449.
The tag names `694061f`, the exact commit every qualification below ran
against; it never moves. This is an experimental x86_64 UEFI kernel for study
and testing in disposable virtual machines. It is not a complete operating
environment, a stable ABI, production software or a completed security audit.

## What ships

- `wizards-bedrock-v0.2.0-x86_64-uefi.zip`: the reproducible shipped boot
  image `bedrock.img`, the kernel ELF `wizard-kernel`, `LICENSE`, the SPDX
  SBOM, third-party notices and every bundled license, with an inner
  `SHA256SUMS`.
- `wizards-bedrock-v0.2.0-evidence.zip`: the v11 evidence bundle that
  `cargo xtask verify-evidence` replays offline.
- `wizards-bedrock-v0.2.0-MANIFEST`: the bundle manifest.
- `SHA256SUMS`: digests of the three files above.

The image boots to Bedrock's diagnostic keyboard prompt after bringing up
paging, the EEVDF scheduler, ring 3, VT-d default-deny DMA translation, NVMe and
read-only FAT32. There is no shell or user program; those belong to Realm.

## Qualification, all on `694061f`

- `cargo xtask ci`: formatting, Clippy and every registered graph; all
  2,235 public API items resolved to compiler-checked callers; 946 host tests
  passed (17 intentionally ignored helpers); release and debug self-tests at
  294/294; shipped and both fail-closed degraded boots.
- `cargo xtask mutate`: the complete curated registry, 2,412 of 2,412
  mutations caught by the check each names, with no survivor or inconclusive
  outcome.
- `cargo xtask model-check`: both TLA+ ring models clean, every model mutation
  violating exactly its invariant.
- `cargo xtask qualify-advisory`: fresh RustSec review of 111 locked
  dependencies against 1,380 advisories, no vulnerability and no warning.
- `cargo xtask debug --check` and `cargo xtask baseline` (three release and
  three debug boots within the reviewed bands).
- VMware Workstation: two independently generated self-test machines at
  294/294 and the shipped machine reaching its prompt with one observed ring-3
  call, each accepted by `cargo xtask qualify-vmware`. The guest reads
  architectural capabilities `0x44` without `RDCL_NO` and selects paired-root
  user isolation.
- `cargo xtask evidence` and `cargo xtask verify-evidence`: reproducible
  shipped kernel and image from independent source, Cargo-home and toolchain
  paths, every record source-bound.

The independent cargo-mutants grade and the owned Codex Security Deep scan run
continuously against `main` and are declared `deferred` in this bundle.

## Verify

Download the four assets and check them with `sha256sum -c SHA256SUMS`; the
runtime archive carries its own `SHA256SUMS` for its members. To replay the
evidence, extract the evidence archive into `target/evidence/` of a clean
checkout of this tag and run `cargo xtask verify-evidence`, which works offline
but requires the recorded tool identities (D-218). The transcripts name the
qualifying host's local paths. Boot `bedrock.img` only in a disposable VM.
