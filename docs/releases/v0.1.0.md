# v0.1.0 — Experimental source preview

This immutable source-only prerelease opens Bedrock for public review and
contributions under D-441. It is not Latest, a qualified diagnostic release,
a complete operating environment or a foundation/phase close. A later qualified
release needs a new version; this tag will not move to upgrade its claims.

The tree contains the x86_64 UEFI Rust kernel, capability/async ABI, host-testable
libraries, build tools, design records and reviewed vendored build inputs.
Use the public-input [Windows GNU quickstart](../../README.md#building--running)
and pinned toolchain. Existing implementation includes scheduling, isolation,
ring-3 entry and read-only NVMe/FAT32 paths; source presence is not fresh boot
evidence. Realm owns desktop, shell, applications and other target-side products;
Ink's compiler-readiness blockers remain external and the handoff remains closed.

Known-open work stays in the [foundation register](../016-pre-wizzy-foundation.md),
including PW-001's full current mutation sweep, PW-003/PW-004's fresh machine
qualification, PW-580/PW-706's isolation qualification, and PW-713 through
PW-720's current-source proof obligations. Rows retain their actual states.
No current VMware or bare-metal support, stable ABI, production readiness or
completed security audit is established. Experiment only in disposable VMs,
away from primary machines and important storage.

The preview gate is disclosure/license review, patch whitespace, fmt,
supply-chain and vendor verification, one shipped release compile, and existing
focused decision/documentation/registry tests on its exact clean commit. The
final SHA, commands, environment and actual outcomes belong in the GitHub
release body, not a self-referential source commit or qualification record.

Full local CI/API audit, unrestricted host tests, curated mutation sweep,
independent grade, Deep scan, model checking, fresh advisory qualification,
QEMU matrices/baselines, both VMware selectors and reproducible evidence
creation/verification are not required or claimed by this source preview.
Qualified diagnostic releases retain all of D-425's stronger obligations,
including exact-source campaign pass/deferred semantics. No new kernel/VM image
or full qualification bundle is distributed; GitHub's tagged source archives
retain the existing vendored inputs and their licenses.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for forks and PRs (including reviewed
AI-assisted work), [issues](https://github.com/wizards-ecosystem/wizards-bedrock/issues)
for ordinary bugs and [SECURITY.md](../../SECURITY.md) for private reports.
First-party source retains MIT; upstream notices and licenses remain in
[supply-chain](../../supply-chain/README.md) and beside vendored inputs.
