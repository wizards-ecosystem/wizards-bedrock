# Security policy

Bedrock is experimental kernel source with no production, audit or hardware-support guarantee.
Reports are welcome for the published releases and current `main`, especially the safe `wost`
boundary, memory protection, capabilities, DMA isolation and the build tooling.

Use GitHub's private [Report a vulnerability](https://github.com/wizards-ecosystem/wizards-bedrock/security/advisories/new)
route. Include the affected commit, the subsystem, the impact, a reproduction and the checks you
ran. Keep exploit details out of public issues. There is no promised response time.
